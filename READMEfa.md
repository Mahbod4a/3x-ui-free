🚀 Mahbod4a

Mahbod4a یک Fork شخصی‌سازی‌شده از 3x-ui است که توسط Mahbod4a نگهداری می‌شود.
این پروژه تجربه اصلی 3x-ui را گسترش داده و یک معماری گیت‌وی چندکشوری ارائه می‌دهد.

بر پایه 3x-ui ساخته شده است. توسط Mahbod4a تغییر داده و نگهداری می‌شود.

این نسخه مشکل اصلی حلقه کرش address already in use را رفع می‌کند:
این مشکل به این دلیل رخ می‌داد که ورودی مستقیم (Direct بدون Tor) و nginx هر دو تلاش می‌کردند روی پورت 8080 گوش دهند، در حالی که nginx هم‌زمان روی پورت 3000 نیز فعال بود.

قبل از تغییر:

قبل از این نسخه:

nginx روی پورت 3000 فعال بود.
xray direct inbound تلاش می‌کرد روی:
0.0.0.0:8080

فعال شود.

در سرویس‌هایی مثل Railway که فقط یک پورت خارجی به کانتینر می‌دهند، این باعث خطا می‌شد:

ERROR - XRAY: Failed to start:
failed to listen on address:
0.0.0.0:8080

bind: address already in use
بعد از تغییر:

اکنون:

فقط nginx روی اینترنت قابل دسترسی است.
nginx فقط روی:
0.0.0.0:3000

گوش می‌دهد.

ورودی مستقیم xray:

127.0.0.1:8080

است و فقط داخلی است.

nginx درخواست‌ها را به آن منتقل می‌کند.

تمام سرویس‌های کشورها نیز فقط روی localhost هستند.

🔎 روش جدید تشخیص کشور

سیستم جدید:

تمام Torها هم‌زمان اجرا می‌شوند.
منتظر می‌ماند Tor کامل آماده شود.
IP خروجی را دریافت می‌کند.
کشور IP را بررسی می‌کند.
اگر کشور درست باشد:
✅ Verified

ثبت می‌شود.

اگر اشتباه باشد:

مدار Tor جدید ساخته می‌شود.
دوباره بررسی می‌شود.

تنظیمات قابل تغییر:

"tor": {
  "bootstrap_timeout": 240,
  "verify_max_retries": 15,
  "verify_retry_sleep": 4,
  "circuit_settle_sleep": 6,
  "parallel_bootstrap": true,
  "parallel_verify": true
}

اگر IP اشتباه باشد:

یک بار دیگر تلاش می‌کند.
اگر باز شکست خورد، کشور موقتاً غیرفعال می‌شود.
🔒 امنیت و نام‌گذاری

ویژگی‌های امنیتی:

✅ اتصال Direct بدون Tor در مسیر /
